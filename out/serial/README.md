# note 連載用原稿 (out/serial/)

書籍 (chapters/ = 単一の真実源) からの派生。**自動生成ではなく、回ごとに編集して確定する**。

## 文体・分量テンプレート (2026-07-17 note 定石リサーチで確定)

- **文体**: 敬体 + 一人称「僕」、要所だけ会話的に緩める (書籍は常体 = 教科書、連載 = 教室の声)
- **改行**: 2〜4 文ごと (note 公式推奨)。書籍の 4〜5 行段落をそのまま持ち込まない
- **見出し**: 800〜1,500 字ごとに ## + 直前に区切り線 (---)
- **タイトル**: 15〜25 字 + サブタイトル。スマホは頭 19 字で折返し = 頭に情報を集める。
  疑問形 or 具体的な主張。「（前編）」「#N」等の構造表記は入れない
- **冒頭 3 行**: 読者の状況 → 問題提起 → 結論の匂わせ (逆三角形)。タイムラインのプレビューを意識
- **分量**: 3,000〜6,000 字基本、専門回で最大 8,000 字
- **表**: 原則文章化 or 箇条書き化 (note は Markdown 表非対応)。残す場合は画像化
- **漢字を開く**: 「殆ど→ほとんど」「勿論→もちろん」等。硬さの正体は常体でなく漢字密度と一文の長さ

## 切り出しルール (全回共通)

1. 切りどころは核心の手前 — 未回収の問いが残る位置で回を終える
2. 無料ラインは「冒頭の問題提起・場面まで」。単体で読んで面白い範囲。`PAID_LINE` コメントが目印
3. 表は note 非対応 — `NOTE-TODO` コメントの箇所を投稿時に画像化 or 箇条書き化する
4. 演習は回末に置き、次回冒頭に読者投稿の講評枠 (🃏) を設ける
5. **『芽吹』は連載に一切出さない** (名前も内容も。書籍限定の差別化要素)。解答例は 📖 案内に置換し、本文の芽吹依存箇所 (検算実演など) は実在カードで書き直す。連載の解答例は読者投稿が主役

## 命名と対応

`NNN-<章>.md`。000=序章 (無料)、001/002=第1章前後編 (無料見本)、003=第2章 (ここから
冒頭無料+有料)。以降は連載開始後、隔週で 1 本ずつ書籍から切り出して編集する。
章が 10k 字を超える場合は前後編に割る。書籍の全内容を連載に載せる必要はない — 回の主役を 1 つ決め、外れる節 (例: 003 で Rams 10 原則を落とした) は書籍に任せる。

- [ ] NOTE-TODO の表を全部処理したか
