# note 連載用原稿 (out/serial/)

書籍 (chapters/ = 単一の真実源) からの派生。**自動生成ではなく、回ごとに編集して確定する**。

## コンセプト (2026-07-17 確定)

**連載は読み物に徹する。** 課題・読者投稿・講評・「あなたの TCG が 1 本できる」という
参加型教材のフレームは連載に持ち込まない (それらは書籍の価値 = 演習チェーン + 『芽吹』通し記録)。
各回は「1 つの面白い問い・事件・カード」で完結する読み物。マガジン名 (仮): 壊れたカードの設計学。

- 書籍 = 体系 + 演習 + 芽吹で「作る」教材
- 連載 = 事例と設計判断の物語を「読む」コンテンツ。書籍の宣伝は各回 1 行まで

## 文体・分量テンプレート (note 定石リサーチで確定)

- **文体**: 敬体 + 一人称「僕」、要所だけ会話的に緩める (書籍は常体 = 教科書、連載 = 語り)
- **改行**: 2〜4 文ごと (note 公式推奨)。書籍の 4〜5 行段落をそのまま持ち込まない
- **見出し**: 800〜1,500 字ごとに ## + 直前に区切り線 (---)
- **タイトル**: 15〜25 字 + サブタイトル。スマホは頭 19 字で折返し = 頭に情報を集める。
  疑問形 or 具体的な主張。「（前編）」「#N」等の構造表記は入れない
- **冒頭 3 行**: 読者の状況 or 具体的な数字・場面 → 問題提起 → 結論の匂わせ (逆三角形)
- **分量**: 2,500〜5,000 字目安 (読み物なので教材時代より軽く)、専門回で最大 8,000 字
- **表**: 原則文章化 or 箇条書き化 (note は Markdown 表非対応)。残す場合は画像化
- **漢字を開く**: 硬さの正体は常体でなく漢字密度と一文の長さ

## 切り出しルール (全回共通)

1. 切りどころは核心の手前 — 未回収の問いが残る位置で回を終える
2. 無料ラインは「冒頭の掴み (数字・場面・問い) まで」。単体で読んで面白い範囲。`PAID_LINE` が目印
3. 表は note 非対応 — `NOTE-TODO` の箇所を投稿時に画像化 or 箇条書き化
4. **参加型の装置 (課題・投稿呼びかけ・講評枠) は置かない**。読者への持ち帰りは
   「好きなカードで試せる」形の軽い誘いまで
5. **「1 本できる」系の約束をしない** (書籍専用の約束)
6. **『芽吹』は連載に一切出さない** (名前も内容も。書籍限定)。芽吹依存箇所は実在カードで書き直す
7. 各回の主役は 1 つ。書籍の全内容を連載に載せない — 外れる節は書籍に任せる
8. 連載は書籍の章順に縛られない。読み物として面白い順に出してよい
   (S 級素材: 射場本の動くカラーパイ / 殿堂解除 / 封入率の運命設計 / ゼットン vs ヨグ 等は独立回向き)

## 命名と対応

`NNN-<内容>.md`。000=序章 (無料)、001/002=コミュニケーション理論・作り方 2 通り (無料見本)、
003=FIRE 検算 (冒頭無料 + 有料)。
